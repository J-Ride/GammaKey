# GammaKey Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build GammaKey, a Windows tray app that switches per-monitor gamma, brightness, contrast, shadows, highlights and NVIDIA digital vibrance by global hotkey, shipped as one self-contained exe.

**Architecture:** Five units with thin interfaces: `CurveBuilder` (pure math, fully unit tested), `DisplayEngine` (Win32 gamma table per monitor, baseline capture and restore, re-apply guard), `VibranceEngine` (optional NVAPI), `HotkeyListener` (Win32 RegisterHotKey on a hidden window), `ProfileStore` (JSON beside the exe). An `AppController` wires them; WinForms `MainForm`, `TrayIcon` and `ToastForm` sit on top. Nothing touches any game process.

**Tech Stack:** C# 12, .NET 8 SDK, WinForms (`net8.0-windows`), System.Text.Json, xUnit. P/Invoke to `gdi32.dll`, `user32.dll`, `nvapi64.dll`. No NuGet packages beyond the xUnit test template.

Spec: `docs/superpowers/specs/2026-11-08-gammakey-design.md`.

## Global Constraints

- Target framework `net8.0-windows`, x64, single self-contained exe, no installer, no admin rights.
- No injection, hooks, overlays, DLL loading into other processes, or keyboard hooks. Only `RegisterHotKey`, `SetDeviceGammaRamp`, DisplayConfig queries and NVAPI calls.
- Vibrance slider range is 50 to 100 (normal 50), matching the NVIDIA Control Panel percent scale. Spec section 5 listed 0 to 100; the driver has no level below the control panel's 50 percent, so 50 to 100 is the implemented range.
- All other slider ranges exactly as spec section 5: gamma 0.3 to 2.8 (normal 1.0), brightness, contrast, shadows, highlights each -100 to +100 (normal 0).
- All sliders at normal must produce the exact identity gamma table (`value = index * 257`).
- Output tables must be non-decreasing so Windows never rejects them for ordering.
- Files beside the exe: `profiles.json`, `baseline.json`, `running.lock`.
- Default profiles on first run: Dark Room, Bright Outdoors, Normal. Hotkeys and reset hotkey start unassigned (empty string).
- Code style per workspace `code-quality.md`: no premature abstractions, WHY comments only, named exports, one class per file.
- Subagent model floor (Jordan's rule): implementers and reviewers run on sonnet or above, never Fable.
- Ponytail fence: `ProfileStore` and `BaselineStore` are persistence (Tier 1). Never drop clamping on load or the atomic write.
- Hard rule from the spec: no proof-of-concept build. Build the full app. Fallbacks in spec section 9 are not built.
- Shell for user-facing commands is PowerShell 5.1. Build commands here are plain `dotnet` invocations that work in either shell.

`src/GammaKey/Color/CurveBuilder.cs`
```csharp
using GammaKey.Models;

namespace GammaKey.Color;

public static class CurveBuilder
{
    public const int Size = 256;

    // Shadows and highlights are limited to a quarter of full scale so their slope never
    // cancels the base curve; combined with the running max below this keeps the table
    // non-decreasing, which Windows requires.
    private const double RegionStrength = 0.25;

    public static ushort[] Build(ColorValues input)
    {
        var v = input.Clamped();
        var ramp = new ushort[Size * 3];
        double contrastFactor = (v.Contrast + 100) / 100.0;
        double brightnessShift = v.Brightness / 200.0;
        double shadows = v.Shadows / 100.0 * RegionStrength;
        double highlights = v.Highlights / 100.0 * RegionStrength;
        ushort previous = 0;

        for (int i = 0; i < Size; i++)
        {
            double x = i / 255.0;
            double y = Math.Pow(x, 1.0 / v.Gamma);
            y = (y - 0.5) * contrastFactor + 0.5;
            y += brightnessShift;

            double shadowWeight = Math.Clamp(1.0 - 2.0 * x, 0.0, 1.0);
            y += shadows * shadowWeight * shadowWeight;

            double highlightWeight = Math.Clamp(2.0 * x - 1.0, 0.0, 1.0);
            y += highlights * highlightWeight * highlightWeight;

            var value = (ushort)Math.Round(Math.Clamp(y, 0.0, 1.0) * 65535.0);
            if (value < previous) value = previous;
            previous = value;

            ramp[i] = value;
            ramp[Size + i] = value;
            ramp[2 * Size + i] = value;
        }

        return ramp;
    }
}
```

`src/GammaKey/Hotkeys/HotkeyCombo.cs`
```csharp
namespace GammaKey.Hotkeys;

public readonly record struct HotkeyCombo(uint Modifiers, Keys Key)
{
    public const uint ModAlt = 0x0001;
    public const uint ModControl = 0x0002;
    public const uint ModShift = 0x0004;
    public const uint ModWin = 0x0008;
    public const uint ModNoRepeat = 0x4000;

    private static readonly Keys[] ModifierKeys =
    {
        Keys.ControlKey, Keys.LControlKey, Keys.RControlKey, Keys.Control,
        Keys.ShiftKey, Keys.LShiftKey, Keys.RShiftKey, Keys.Shift,
        Keys.Menu, Keys.LMenu, Keys.RMenu, Keys.Alt,
        Keys.LWin, Keys.RWin, Keys.None,
    };

    public static bool TryParse(string text, out HotkeyCombo combo)
    {
        combo = default;
        if (string.IsNullOrWhiteSpace(text)) return false;

        var parts = text.Split('+', StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries);
        if (parts.Length == 0) return false;

        uint modifiers = 0;
        for (int i = 0; i < parts.Length - 1; i++)
        {
            switch (parts[i].ToLowerInvariant())
            {
                case "ctrl":
                case "control": modifiers |= ModControl; break;
                case "alt": modifiers |= ModAlt; break;
                case "shift": modifiers |= ModShift; break;
                case "win":
                case "windows": modifiers |= ModWin; break;
                default: return false;
            }
        }

        var last = parts[^1];
        if (!Enum.TryParse<Keys>(last, ignoreCase: true, out var key)) return false;
        if (ModifierKeys.Contains(key)) return false;

        combo = new HotkeyCombo(modifiers, key);
        return true;
    }

    public override string ToString()
    {
        var parts = new List<string>(5);
        if ((Modifiers & ModControl) != 0) parts.Add("Ctrl");
        if ((Modifiers & ModAlt) != 0) parts.Add("Alt");
        if ((Modifiers & ModShift) != 0) parts.Add("Shift");
        if ((Modifiers & ModWin) != 0) parts.Add("Win");
        parts.Add(Key.ToString());
        return string.Join('+', parts);
    }
}
```

using System.Text.Json.Serialization;
using GammaKey.Models;

namespace GammaKey.Storage;

public sealed class ProfileStore
{
    public static readonly JsonSerializerOptions JsonOptions = new()
    {
        WriteIndented = true,
        PropertyNamingPolicy = JsonNamingPolicy.CamelCase,
        PropertyNameCaseInsensitive = true,
        DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull,
    };

    public string Path { get; }

    public ProfileStore(string path)
    {
        Path = path;
    }

    public AppSettings Load()
    {
        if (!File.Exists(Path)) return Defaults();

        AppSettings? settings = null;
        try
        {
            settings = JsonSerializer.Deserialize<AppSettings>(File.ReadAllText(Path), JsonOptions);
        }
        catch (JsonException)
        {
            // A half-written or hand-edited file must never lose the user's profiles silently,
            // so keep a copy next to it before falling back.
            File.Copy(Path, Path + ".corrupt", overwrite: true);
        }

        if (settings is null) return Defaults();

        foreach (var profile in settings.Profiles)
        {
            profile.Values = profile.Values.Clamped();
            profile.Target ??= MonitorTarget.ForPrimary();
            if (string.IsNullOrWhiteSpace(profile.Id)) profile.Id = Guid.NewGuid().ToString("N");
        }
        settings.ResetHotkey ??= "";
        return settings;
    }

    public void Save(AppSettings settings)
    {
        var dir = System.IO.Path.GetDirectoryName(Path);
        if (!string.IsNullOrEmpty(dir)) Directory.CreateDirectory(dir);

        var temp = Path + ".tmp";
        File.WriteAllText(temp, JsonSerializer.Serialize(settings, JsonOptions));
        File.Move(temp, Path, overwrite: true);
    }

    public static AppSettings Defaults() => new()
    {
        Profiles =
        {
            new Profile { Name = "Dark Room", Values = new ColorValues(1.5, 15, 0, 40, 0, 60) },
            new Profile { Name = "Bright Outdoors", Values = new ColorValues(0.85, 0, 10, 0, -20, 55) },

    private static extern IntPtr CreateDC(string? driver, string device, string? output, IntPtr initData);

    private static extern bool GetDeviceGammaRamp(IntPtr hdc, [Out] ushort[] ramp);

    public static ushort[]? Get(string deviceName)
    {
        var hdc = CreateDC("DISPLAY", deviceName, null, IntPtr.Zero);
        if (hdc == IntPtr.Zero) return null;
        try
        {
            var ramp = new ushort[RampLength];
            return GetDeviceGammaRamp(hdc, ramp) ? ramp : null;
        }
        finally
        {
            DeleteDC(hdc);
        }
    }

    public static bool Set(string deviceName, ushort[] ramp)
    {
        if (ramp.Length != RampLength) throw new ArgumentException("Ramp must have 768 entries", nameof(ramp));
        var hdc = CreateDC("DISPLAY", deviceName, null, IntPtr.Zero);
        if (hdc == IntPtr.Zero) return false;
        try
        {
            return SetDeviceGammaRamp(hdc, ramp);
        }
        finally
        {
            DeleteDC(hdc);
        }
    }

using System.Runtime.InteropServices;
using static GammaKey.Display.DisplayConfigNative;

namespace GammaKey.Display;

public static class MonitorEnumerator
{
    public static IReadOnlyList<MonitorInfo> GetMonitors()
    {
        var primaryName = FindPrimaryDeviceName();
        var result = new List<MonitorInfo>();
        var usedNames = new Dictionary<string, int>(StringComparer.OrdinalIgnoreCase);

        if (GetDisplayConfigBufferSizes(QdcOnlyActivePaths, out var pathCount, out var modeCount) != 0)
            return FallbackFromGdi(primaryName);

        var paths = new PathInfo[pathCount];
        var modes = new ModeInfo[modeCount];
        if (QueryDisplayConfig(QdcOnlyActivePaths, ref pathCount, paths, ref modeCount, modes, IntPtr.Zero) != 0)
            return FallbackFromGdi(primaryName);

        for (int i = 0; i < pathCount; i++)
        {
            var path = paths[i];

            var source = new SourceDeviceName
            {
                Header = new DeviceInfoHeader
                {
                    Type = DeviceInfoGetSourceName,
                    Size = (uint)Marshal.SizeOf<SourceDeviceName>(),
                    AdapterId = path.SourceInfo.AdapterId,
                    Id = path.SourceInfo.Id,
                },
            };
            if (DisplayConfigGetDeviceInfo(ref source) != 0) continue;

            var target = new TargetDeviceName
            {
                Header = new DeviceInfoHeader
                {
                    Type = DeviceInfoGetTargetName,
                    Size = (uint)Marshal.SizeOf<TargetDeviceName>(),
                    AdapterId = path.TargetInfo.AdapterId,
                    Id = path.TargetInfo.Id,
                },
            };
            var friendly = DisplayConfigGetDeviceInfo(ref target) == 0 ? target.MonitorFriendlyDeviceName : "";
            if (string.IsNullOrWhiteSpace(friendly)) friendly = $"Display {result.Count + 1}";

            var color = new AdvancedColorInfo
            {
                Header = new DeviceInfoHeader
                {
                    Type = DeviceInfoGetAdvancedColorInfo,
                    Size = (uint)Marshal.SizeOf<AdvancedColorInfo>(),
                    AdapterId = path.TargetInfo.AdapterId,
                    Id = path.TargetInfo.Id,
                },
            };
            bool hdrOn = DisplayConfigGetDeviceInfo(ref color) == 0 && (color.Value & AdvancedColorEnabledBit) != 0;

            // Two identical monitors report the same friendly name; number the repeats so the
            // profile target can still name one of them.
            if (usedNames.TryGetValue(friendly, out var seen))
            {
                usedNames[friendly] = seen + 1;
                friendly = $"{friendly} ({seen + 1})";
            }
            else
            {
                usedNames[friendly] = 1;
            }

            var gdiName = source.ViewGdiDeviceName;
            result.Add(new MonitorInfo(gdiName, friendly, gdiName.Equals(primaryName, StringComparison.OrdinalIgnoreCase), hdrOn));
        }

        return result.Count > 0 ? result : FallbackFromGdi(primaryName);
    }

    private static string? FindPrimaryDeviceName()
    {
        var device = new DisplayDevice { Cb = Marshal.SizeOf<DisplayDevice>() };
        for (uint i = 0; EnumDisplayDevices(null, i, ref device, 0); i++)
        {
            if ((device.StateFlags & DisplayDevicePrimary) != 0) return device.DeviceName;
            device.Cb = Marshal.SizeOf<DisplayDevice>();
        }
        return null;
    }

    private static IReadOnlyList<MonitorInfo> FallbackFromGdi(string? primaryName)
    {
        var result = new List<MonitorInfo>();
        var device = new DisplayDevice { Cb = Marshal.SizeOf<DisplayDevice>() };
        for (uint i = 0; EnumDisplayDevices(null, i, ref device, 0); i++)
        {
            if ((device.StateFlags & DisplayDeviceActive) != 0)
                result.Add(new MonitorInfo(device.DeviceName, $"Display {result.Count + 1}", device.DeviceName == primaryName, false));
            device.Cb = Marshal.SizeOf<DisplayDevice>();
        }
        return result;
    }
}

using GammaKey.Color;
using GammaKey.Models;
using GammaKey.Storage;

namespace GammaKey.Display;

public sealed record ApplyResult(bool Accepted, string? Note);

public sealed class DisplayEngine
{
    // Drivers may round the table slightly on read-back; anything within this is "the same".
    private const int Tolerance = 512;

    private ushort[]? _activeRamp;
    private IReadOnlyList<MonitorInfo> _activeMonitors = Array.Empty<MonitorInfo>();

    public IReadOnlyList<MonitorInfo> GetMonitors() => MonitorEnumerator.GetMonitors();

    public IReadOnlyList<MonitorInfo> ResolveTargets(MonitorTarget target, out string? note)
    {
        note = null;
        var monitors = GetMonitors();
        if (monitors.Count == 0) return monitors;

        var primary = monitors.FirstOrDefault(m => m.IsPrimary) ?? monitors[0];

        switch (target.Mode)
        {
            case MonitorTarget.All:
                return monitors;
            case MonitorTarget.Monitor:
                var match = monitors.FirstOrDefault(m => m.FriendlyName.Equals(target.MonitorName, StringComparison.OrdinalIgnoreCase));
                if (match is not null) return new[] { match };
                note = $"{target.MonitorName} not connected, used primary";
                return new[] { primary };
            default:
                return new[] { primary };
        }
    }

    public void CaptureBaseline(Baseline into)
    {
        foreach (var monitor in GetMonitors())
        {
            var ramp = GammaRampNative.Get(monitor.DeviceName);
            if (ramp is not null) into.Ramps[monitor.DeviceName] = ramp;
        }
    }

    public void RestoreBaseline(Baseline from)
    {
        foreach (var (deviceName, ramp) in from.Ramps)
            GammaRampNative.Set(deviceName, ramp);
        ClearActive();
    }

    public ApplyResult Apply(ColorValues values, IReadOnlyList<MonitorInfo> monitors)
    {
        var ramp = CurveBuilder.Build(values);
        bool anyAccepted = false;
        bool anyRefused = false;

        foreach (var monitor in monitors)
        {
            // Windows returns TRUE even when it silently refuses an extreme table, so the
            // read-back is the only honest signal.
            GammaRampNative.Set(monitor.DeviceName, ramp);
            var readBack = GammaRampNative.Get(monitor.DeviceName);
            if (readBack is not null && Matches(readBack, ramp)) anyAccepted = true;
            else anyRefused = true;
        }

        _activeRamp = ramp;
        _activeMonitors = monitors;

        if (anyRefused && !anyAccepted)
            return new ApplyResult(false, "Windows refused this curve, reduce the sliders");
        if (anyRefused)
            return new ApplyResult(true, "One monitor refused the curve");
        return new ApplyResult(true, null);
    }

    public void ClearActive()
    {
        _activeRamp = null;
        _activeMonitors = Array.Empty<MonitorInfo>();
    }

    public bool ReapplyIfCleared()
    {
        if (_activeRamp is null) return false;
        bool reapplied = false;
        foreach (var monitor in _activeMonitors)
        {
            var current = GammaRampNative.Get(monitor.DeviceName);
            if (current is null || Matches(current, _activeRamp)) continue;
            GammaRampNative.Set(monitor.DeviceName, _activeRamp);
            reapplied = true;
        }
        return reapplied;
    }

    private static bool Matches(ushort[] a, ushort[] b)
    {
        for (int i = 0; i < a.Length; i++)
            if (Math.Abs(a[i] - b[i]) > Tolerance) return false;
        return true;
    }
}

    [UnmanagedFunctionPointer(CallingConvention.Cdecl)]
    public delegate int EnumNvidiaDisplayHandleDelegate(int index, out IntPtr handle);

    [UnmanagedFunctionPointer(CallingConvention.Cdecl)]
    public delegate int GetAssociatedNvidiaDisplayNameDelegate(IntPtr handle, byte[] name);

    [UnmanagedFunctionPointer(CallingConvention.Cdecl)]
    public delegate int GetDvcInfoDelegate(IntPtr handle, uint outputId, ref DvcInfo info);

    [UnmanagedFunctionPointer(CallingConvention.Cdecl)]
    public delegate int SetDvcLevelDelegate(IntPtr handle, uint outputId, int level);

    public static InitializeDelegate? Initialize => Resolve<InitializeDelegate>(IdInitialize);
    public static EnumNvidiaDisplayHandleDelegate? EnumNvidiaDisplayHandle => Resolve<EnumNvidiaDisplayHandleDelegate>(IdEnumNvidiaDisplayHandle);
    public static GetAssociatedNvidiaDisplayNameDelegate? GetAssociatedNvidiaDisplayName => Resolve<GetAssociatedNvidiaDisplayNameDelegate>(IdGetAssociatedNvidiaDisplayName);
    public static GetDvcInfoDelegate? GetDvcInfo => Resolve<GetDvcInfoDelegate>(IdGetDvcInfo);
    public static SetDvcLevelDelegate? SetDvcLevel => Resolve<SetDvcLevelDelegate>(IdSetDvcLevel);

    private static T? Resolve<T>(uint id) where T : Delegate
    {
        var ptr = QueryInterface(id);
        return ptr == IntPtr.Zero ? null : Marshal.GetDelegateForFunctionPointer<T>(ptr);
    }
}

using System.Text;
using GammaKey.Models;
using GammaKey.Storage;

namespace GammaKey.Vibrance;

public sealed class VibranceEngine
{
    private readonly Dictionary<string, IntPtr> _handlesByDevice = new(StringComparer.OrdinalIgnoreCase);
    private NvApiNative.GetDvcInfoDelegate? _getInfo;
    private NvApiNative.SetDvcLevelDelegate? _setLevel;

    public bool IsAvailable { get; private set; }
    public string? UnavailableReason { get; private set; }

    public VibranceEngine()
    {
        try
        {
            Initialize();
        }
        catch (DllNotFoundException)
        {
            UnavailableReason = "NVIDIA driver not found";
        }
        catch (EntryPointNotFoundException)
        {
            UnavailableReason = "NVIDIA driver too old";
        }
    }

    private void Initialize()
    {
        var init = NvApiNative.Initialize;
        var enumHandle = NvApiNative.EnumNvidiaDisplayHandle;
        var getName = NvApiNative.GetAssociatedNvidiaDisplayName;
        _getInfo = NvApiNative.GetDvcInfo;
        _setLevel = NvApiNative.SetDvcLevel;

        if (init is null || enumHandle is null || getName is null || _getInfo is null || _setLevel is null)
        {
            UnavailableReason = "NVIDIA driver missing vibrance support";
            return;
        }
        if (init() != NvApiNative.NvApiOk)
        {
            UnavailableReason = "NVIDIA driver failed to start";
            return;
        }

        var nameBuffer = new byte[64];
        for (int i = 0; ; i++)
        {
            var status = enumHandle(i, out var handle);
            if (status != NvApiNative.NvApiOk) break;
            Array.Clear(nameBuffer);
            if (getName(handle, nameBuffer) != NvApiNative.NvApiOk) continue;
            var name = Encoding.ASCII.GetString(nameBuffer).TrimEnd('\0');
            if (name.Length > 0) _handlesByDevice[name] = handle;
        }

        IsAvailable = _handlesByDevice.Count > 0;
        if (!IsAvailable) UnavailableReason = "No monitor on an NVIDIA output";
    }

    public int? GetSlider(string deviceName)
    {
        var raw = GetRaw(deviceName, out var info);
        if (raw is null) return null;
        int span = Math.Max(1, info.MaxLevel - info.MinLevel);
        double fraction = (raw.Value - info.MinLevel) / (double)span;
        return (int)Math.Round(ColorValues.VibranceMin + fraction * (ColorValues.VibranceMax - ColorValues.VibranceMin));
    }

    public bool SetSlider(string deviceName, int slider)
    {
        if (GetRaw(deviceName, out var info) is null) return false;
        slider = Math.Clamp(slider, ColorValues.VibranceMin, ColorValues.VibranceMax);
        double fraction = (slider - ColorValues.VibranceMin) / (double)(ColorValues.VibranceMax - ColorValues.VibranceMin);
        int level = info.MinLevel + (int)Math.Round(fraction * (info.MaxLevel - info.MinLevel));
        return SetRaw(deviceName, level);
    }

    public void CaptureBaseline(Baseline into)
    {
        foreach (var device in _handlesByDevice.Keys)
        {
            var raw = GetRaw(device, out _);
            if (raw is not null) into.VibranceLevels[device] = raw.Value;
        }
    }

    public void RestoreBaseline(Baseline from)
    {
        foreach (var (device, level) in from.VibranceLevels)
            SetRaw(device, level);
    }

    private int? GetRaw(string deviceName, out NvApiNative.DvcInfo info)
    {
        info = NvApiNative.DvcInfo.Create();
        if (!IsAvailable || _getInfo is null || !_handlesByDevice.TryGetValue(deviceName, out var handle)) return null;
        return _getInfo(handle, 0, ref info) == NvApiNative.NvApiOk ? info.CurrentLevel : null;
    }

    private bool SetRaw(string deviceName, int level)
    {
        if (!IsAvailable || _setLevel is null || !_handlesByDevice.TryGetValue(deviceName, out var handle)) return false;
        return _setLevel(handle, 0, level) == NvApiNative.NvApiOk;
    }
}

using System.Runtime.InteropServices;

namespace GammaKey.Hotkeys;

public sealed class HotkeyListener : NativeWindow, IDisposable
{
    private const int WmHotkey = 0x0312;
    private readonly HashSet<int> _registered = new();

    [DllImport("user32.dll")]
    private static extern bool RegisterHotKey(IntPtr hWnd, int id, uint modifiers, uint vk);

    [DllImport("user32.dll")]
    private static extern bool UnregisterHotKey(IntPtr hWnd, int id);

    public event Action<int>? Pressed;

    public HotkeyListener()
    {
        // A message-only window: never shown, only receives WM_HOTKEY.
        CreateHandle(new CreateParams { Parent = new IntPtr(-3) });
    }

    public bool Register(int id, HotkeyCombo combo)
    {
        if (_registered.Contains(id)) UnregisterHotKey(Handle, id);
        bool ok = RegisterHotKey(Handle, id, combo.Modifiers | HotkeyCombo.ModNoRepeat, (uint)combo.Key);
        if (ok) _registered.Add(id);
        else _registered.Remove(id);
        return ok;
    }

    public void UnregisterAll()
    {
        foreach (var id in _registered) UnregisterHotKey(Handle, id);
        _registered.Clear();
    }

    protected override void WndProc(ref Message m)
    {
        if (m.Msg == WmHotkey) Pressed?.Invoke(m.WParam.ToInt32());
        base.WndProc(ref m);
    }

    public void Dispose()
    {
        UnregisterAll();
        DestroyHandle();
    }
}

using GammaKey.Display;
using GammaKey.Hotkeys;
using GammaKey.Models;
using GammaKey.Storage;
using GammaKey.Vibrance;

namespace GammaKey.App;

public sealed class AppController : IDisposable
{
    private const int ResetHotkeyId = 1;
    private const int FirstProfileHotkeyId = 100;
    private const int GuardIntervalMs = 3000;

    private readonly ProfileStore _profileStore;
    private readonly BaselineStore _baselineStore;
    private readonly HotkeyListener _hotkeys = new();
    private readonly System.Windows.Forms.Timer _guard = new() { Interval = GuardIntervalMs };
    private readonly Dictionary<int, string> _profileIdsByHotkeyId = new();
    private Baseline _baseline = new();

    public string BaseDirectory { get; }
    public string LockPath => Path.Combine(BaseDirectory, "running.lock");
    public AppSettings Settings { get; private set; }
    public DisplayEngine Display { get; } = new();
    public VibranceEngine Vibrance { get; } = new();

    public event Action<Profile, string?>? ProfileApplied;
    public event Action<string>? ResetApplied;
    public event Action? SettingsChanged;

    public AppController(string baseDirectory)
    {
        BaseDirectory = baseDirectory;
        _profileStore = new ProfileStore(Path.Combine(baseDirectory, "profiles.json"));
        _baselineStore = new BaselineStore(Path.Combine(baseDirectory, "baseline.json"));
        Settings = _profileStore.Load();
        _hotkeys.Pressed += OnHotkeyPressed;
        _guard.Tick += (_, _) => { if (Settings.GuardEnabled) Display.ReapplyIfCleared(); };
    }

    public void Start()
    {
        // A lock file left behind means the last run died with a curve applied. Put the
        // original back first so the fresh baseline is the real one, not the stale profile.
        var previous = _baselineStore.Load();
        if (File.Exists(LockPath) && previous is not null)
        {
            Display.RestoreBaseline(previous);
            Vibrance.RestoreBaseline(previous);
        }

        _baseline = new Baseline();
        Display.CaptureBaseline(_baseline);
        Vibrance.CaptureBaseline(_baseline);
        _baselineStore.Save(_baseline);
        File.WriteAllText(LockPath, DateTime.Now.ToString("O"));

        if (!File.Exists(_profileStore.Path)) _profileStore.Save(Settings);

        RegisterHotkeys();
        _guard.Start();
    }

    public IReadOnlyList<string> RegisterHotkeys()
    {
        _hotkeys.UnregisterAll();
        _profileIdsByHotkeyId.Clear();
        var failed = new List<string>();

        if (HotkeyCombo.TryParse(Settings.ResetHotkey, out var resetCombo) && !_hotkeys.Register(ResetHotkeyId, resetCombo))
            failed.Add("Reset");

        int nextId = FirstProfileHotkeyId;
        foreach (var profile in Settings.Profiles)
        {
            if (!HotkeyCombo.TryParse(profile.Hotkey, out var combo)) continue;
            if (_hotkeys.Register(nextId, combo)) _profileIdsByHotkeyId[nextId] = profile.Id;
            else failed.Add(profile.Name);
            nextId++;
        }
        return failed;
    }

    public ApplyResult ApplyProfile(Profile profile)
    {
        var result = Preview(profile.Values, profile.Target);
        ProfileApplied?.Invoke(profile, result.Note);
        return result;
    }

    public ApplyResult Preview(ColorValues values, MonitorTarget target)
    {
        var monitors = Display.ResolveTargets(target, out var note);
        var result = Display.Apply(values, monitors);
        if (Vibrance.IsAvailable)
            foreach (var monitor in monitors) Vibrance.SetSlider(monitor.DeviceName, values.Vibrance);
        return result with { Note = result.Note ?? note };
    }

    public void Reset()
    {
        Display.RestoreBaseline(_baseline);
        Vibrance.RestoreBaseline(_baseline);
        ResetApplied?.Invoke("Reset to original");
    }

    public void Save()
    {
        _profileStore.Save(Settings);
        SettingsChanged?.Invoke();
    }

    public void SetStartWithWindows(bool on)
    {
        StartupRegistration.Set(on);
        Settings.StartWithWindows = on;
        Save();
    }

    public void Shutdown()
    {
        _guard.Stop();
        _hotkeys.UnregisterAll();
        Display.RestoreBaseline(_baseline);
        Vibrance.RestoreBaseline(_baseline);
        if (File.Exists(LockPath)) File.Delete(LockPath);
    }

    private void OnHotkeyPressed(int id)
    {
        if (id == ResetHotkeyId)
        {
            Reset();
            return;
        }
        if (!_profileIdsByHotkeyId.TryGetValue(id, out var profileId)) return;
        var profile = Settings.Profiles.FirstOrDefault(p => p.Id == profileId);
        if (profile is not null) ApplyProfile(profile);
    }

    public void Dispose()
    {
        _guard.Dispose();
        _hotkeys.Dispose();
    }
}

        RefreshProfileList();

    }

        {
            case Button b:
                b.FlatStyle = FlatStyle.Flat;
                b.FlatAppearance.BorderColor = Border;
                b.FlatAppearance.MouseOverBackColor = SurfaceRaised;
                b.BackColor = Surface;
                b.Height = ControlHeight;
                b.Padding = new Padding(Space3, 0, Space3, 0);
                break;
            case TextBox t:
                t.BackColor = Surface;
                t.BorderStyle = BorderStyle.FixedSingle;
                break;
            case ComboBox c:
                c.BackColor = Surface;
                c.FlatStyle = FlatStyle.Flat;
                break;
            case NumericUpDown n:
                n.BackColor = Surface;
                n.BorderStyle = BorderStyle.FixedSingle;
                break;
            case ListBox l:
                l.BackColor = Surface;
                l.BorderStyle = BorderStyle.None;
                l.ItemHeight = ControlHeight;
                l.DrawMode = DrawMode.OwnerDrawFixed;
                l.DrawItem += DrawListItem;
                break;
            case CheckBox cb:
                cb.FlatStyle = FlatStyle.Flat;
                break;
            default:
                control.BackColor = Background;
                break;

        foreach (Control child in control.Controls) ApplyRecursive(child);

        TextRenderer.DrawText(e.Graphics, list.Items[e.Index]?.ToString(), Label, textBounds, TextPrimary, TextFormatFlags.VerticalCenter | TextFormatFlags.Left);

namespace GammaKey.UI;

public sealed class GkSlider : Control
{
    private int _minimum;
    private int _maximum = 100;
    private int _value;
    private bool _dragging;

    public event EventHandler? ValueChanged;

    public GkSlider()
    {
        SetStyle(ControlStyles.AllPaintingInWmPaint | ControlStyles.OptimizedDoubleBuffer | ControlStyles.UserPaint | ControlStyles.ResizeRedraw | ControlStyles.Selectable, true);
        Height = Theme.ControlHeight;
        Width = 320;
        TabStop = true;
    }

    public int Minimum { get => _minimum; set { _minimum = value; Value = _value; } }
    public int Maximum { get => _maximum; set { _maximum = value; Value = _value; } }

    public int Value
    {
        get => _value;
        set
        {
            var clamped = Math.Clamp(value, _minimum, _maximum);
            if (clamped == _value) { Invalidate(); return; }
            _value = clamped;
            Invalidate();
            ValueChanged?.Invoke(this, EventArgs.Empty);
        }
    }

    // Where "normal" sits so the fill can grow from it in both directions.
    public int Origin { get; set; }

    private Rectangle TrackRect => new(Theme.SliderThumbSize / 2, (Height - Theme.SliderTrackHeight) / 2, Width - Theme.SliderThumbSize, Theme.SliderTrackHeight);

    private int ValueToX(int v)
    {
        var t = TrackRect;
        double fraction = _maximum == _minimum ? 0 : (v - _minimum) / (double)(_maximum - _minimum);
        return t.Left + (int)Math.Round(fraction * t.Width);
    }

    private int XToValue(int x)
    {
        var t = TrackRect;
        double fraction = Math.Clamp((x - t.Left) / (double)t.Width, 0, 1);
        return _minimum + (int)Math.Round(fraction * (_maximum - _minimum));
    }

    protected override void OnPaint(PaintEventArgs e)
    {
        var g = e.Graphics;
        g.SmoothingMode = System.Drawing.Drawing2D.SmoothingMode.AntiAlias;
        g.Clear(Parent?.BackColor ?? Theme.Background);

        var track = TrackRect;
        using var trackBrush = new SolidBrush(Enabled ? Theme.Border : Theme.Disabled);
        FillRounded(g, trackBrush, track, track.Height / 2);

        int originX = ValueToX(Math.Clamp(Origin, _minimum, _maximum));
        int valueX = ValueToX(_value);
        var fill = Rectangle.FromLTRB(Math.Min(originX, valueX), track.Top, Math.Max(originX, valueX), track.Bottom);
        if (fill.Width > 0)
        {
            using var fillBrush = new SolidBrush(Enabled ? Theme.Accent : Theme.Disabled);
            FillRounded(g, fillBrush, fill, track.Height / 2);
        }

        int thumb = Theme.SliderThumbSize;
        var thumbRect = new Rectangle(valueX - thumb / 2, (Height - thumb) / 2, thumb, thumb);
        using var thumbBrush = new SolidBrush(Enabled ? (_dragging ? Theme.AccentHover : Theme.TextPrimary) : Theme.Disabled);
        g.FillEllipse(thumbBrush, thumbRect);
        if (Focused && Enabled)
        {
            using var focus = new Pen(Theme.Accent, 2f);
            g.DrawEllipse(focus, Rectangle.Inflate(thumbRect, 3, 3));
        }
    }

    private static void FillRounded(Graphics g, Brush brush, Rectangle r, int radius)
    {
        if (r.Width <= 0 || r.Height <= 0) return;
        using var path = new System.Drawing.Drawing2D.GraphicsPath();
        int d = Math.Max(1, radius * 2);
        path.AddArc(r.Left, r.Top, d, d, 180, 90);
        path.AddArc(r.Right - d, r.Top, d, d, 270, 90);
        path.AddArc(r.Right - d, r.Bottom - d, d, d, 0, 90);
        path.AddArc(r.Left, r.Bottom - d, d, d, 90, 90);
        path.CloseFigure();
        g.FillPath(brush, path);
    }

    protected override void OnMouseDown(MouseEventArgs e)
    {
        if (!Enabled || e.Button != MouseButtons.Left) return;
        Focus();
        _dragging = true;
        Value = XToValue(e.X);
    }

    protected override void OnMouseMove(MouseEventArgs e)
    {
        if (_dragging) Value = XToValue(e.X);
    }

    protected override void OnMouseUp(MouseEventArgs e)
    {
        _dragging = false;
        Invalidate();
    }

    protected override bool IsInputKey(Keys keyData) => keyData is Keys.Left or Keys.Right or Keys.Home or Keys.End || base.IsInputKey(keyData);

    protected override void OnKeyDown(KeyEventArgs e)
    {
        int step = e.Shift ? 10 : 1;
        switch (e.KeyCode)
        {
            case Keys.Left: Value -= step; e.Handled = true; break;
            case Keys.Right: Value += step; e.Handled = true; break;
            case Keys.Home: Value = _minimum; e.Handled = true; break;
            case Keys.End: Value = _maximum; e.Handled = true; break;
        }
        base.OnKeyDown(e);
    }

    protected override void OnMouseWheel(MouseEventArgs e)
    {
        Value += Math.Sign(e.Delta);
        base.OnMouseWheel(e);
    }

    protected override void OnEnabledChanged(EventArgs e)
    {
        base.OnEnabledChanged(e);
        Invalidate();
    }
}

```markdown
# GammaKey

Switch your monitor's gamma, brightness, contrast, shadows, highlights and NVIDIA vibrance with a hotkey.
Made for Escape from Tarkov's dark corners, works anywhere on the desktop.

![Main window](docs/screenshots/main-window.png)

## Run it

1. Download `GammaKey.exe` and put it in its own folder (it writes `profiles.json` beside itself).
2. Double-click it. Windows SmartScreen may warn because the exe is unsigned: click **More info**, then **Run anyway**.
3. An icon appears by the clock. Left-click it to open the window.
4. Pick a profile, drag the sliders until the screen looks right, click the **Hotkey** box and press your key combo, then **Save**.
5. Set a **Reset hotkey** in Settings so you can always get back to normal.

Profiles live in `profiles.json`. Copy that file to a friend's folder to share your setup.

## How it works, and why it is safe

GammaKey changes the colour curve your graphics card applies to the whole screen, the same control the
NVIDIA Control Panel's "Adjust desktop color settings" page uses. It talks only to Windows and the graphics
driver. It never opens, reads, hooks or injects anything into a game. It runs without administrator rights.

## Notes

- **HDR.** Tune the sliders with HDR on if you game with HDR on; what you see is what is saved.
- **Vibrance** needs an NVIDIA card. On other cards the slider is greyed out and everything else works.
- **Flicker in Discord or Chrome** with a curve active is a known NVIDIA driver quirk with custom curves.
  Update the driver, or press Reset while not gaming.
- **Original settings** are saved to `baseline.json` on start and restored on Reset, on Quit, and on the
  next start if GammaKey was closed uncleanly.

## Build from source

Needs the .NET 8 SDK.

    .\publish.ps1

Output: `publish\GammaKey.exe`.
```
